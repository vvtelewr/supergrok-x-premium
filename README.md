## 模型和新功能：谁能先用到新东西

模型获取这一项，两条线这几年反复变化，几个关键节点先捋一下：

- Grok 4 发布时面向 SuperGrok 和 X Premium+ 用户开放，后来的 Grok 4.1 下放给了全体用户。所以“能不能用上新模型”现在已经不是区分付费档位的硬标准。
- 标准 SuperGrok 目前的基线模型是 Grok 4.6，图像和视频生成为标配。
- Grok Build（用于搭建应用的早期测试功能）对 SuperGrok 和 X Premium+ 订阅者开放。
- **SuperGrok Heavy 独占 Grok 4 Heavy 的多智能体推理模式**——多个“专家”同时拆解一个复杂问题，适合长链路的科研、编程和分析任务。Plus 档不包含这个模式。
- SuperGrok Plus 的增量在别处：1080p 视频生成、更高的用量上限、高峰期优先。

简单说，日常对话和搜索，30 美元的标准 SuperGrok 已经给全了；Heavy 是给跑多智能体工作流的人准备的专用工具，不是“更流畅的聊天”。

## 常见问题

**有叫"Grok Premium"的套餐吗？**
没有。xAI 的付费产品线叫 SuperGrok（Lite / 标准 / Plus / Heavy）；"Premium"和"Premium+"是 X 平台会员的名字。

**不花钱能用 Grok 吗？**
能，部分地区开放免费档，用量有限。第三方信息显示大约每几小时 10 条左右，且图像和视频生成现在需要付费档。

**订阅里包含 API 额度吗？**
不包含。订阅只覆盖 Grok 官网和 App 的消费级使用；开发者调用 API 要在 xAI 开发者控制台单独按 token 付费。目前 Grok 4.6 是每百万 token 输入 2 美元、输出 6 美元，Grok 4.3 是 1.25 / 2.50 美元。注意输入超过 20 万 token 后费率翻倍，跑长文档时预算要按两倍算。

**买了 X Premium+ 还需要 SuperGrok 吗？**
看你怎么用。Premium+ 的 Grok 额度约为独立 SuperGrok 的三分之一，DeepSearch 和 Think 都是受限版。偶尔在 X 里问问题够了；把 Grok 当生产力工具用，加购 SuperGrok 更实在。

**SuperGrok 和 X Premium 能同时买吗？**
可以，两者账号体系独立。但先想清楚需求：只为 Grok 付费的话，买一份通常就够了。同时买两份却只用其中一边，是这笔消费里最常见的浪费。
